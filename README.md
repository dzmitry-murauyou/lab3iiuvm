# ATA Analyzer — ЛР №3, вариант А7

Низкоуровневый ATA-контроллер через порты ввода-вывода.
Проект Visual Studio 2008 (Win32, x86), рассчитан на **Windows XP x32**.

Что делает программа (ничего сверх варианта А7):

- обращается к регистрам Primary Channel (`0x1F0–0x1F7`, AS/DC `0x3F6`)
  и Secondary Channel (`0x170–0x177`, AS/DC `0x376`) напрямую через
  `_inp` / `_outp` / `_inpw`, доступ к портам даёт драйвер HexIO;
- кнопка **Soft Reset (SRST)** — программный сброс через бит 2 регистра DC;
- ждёт снятия `BSY` и установки `DRDY` в регистре SR/AS;
- отправляет **IDENTIFY DEVICE (0xEC)** и читает 512 байт (256 слов из
  регистра данных) в режиме PIO;
- показывает: модель (word 27–46), серийный номер (word 10–19), прошивку
  (word 23–26), объём (word 60–61 LBA28 / 100–103 LBA48), признак LBA
  (word 49), тип HDD/SSD (word 217); ATAPI определяется по сигнатуре
  `CL=0x14, CH=0xEB` и читается командой `0xA1`;
- пустой канал — если регистр состояния вернул `0x00` или `0xFF`;
- кнопка **Сохранить отчёт** пишет `ATA_Report.txt` в текущий рабочий
  каталог (при запуске из VS2008 — в папку проекта `ATAAnalyzer`).

Оформление: одно окно, простая тёмная тема (фон `RGB(32,32,32)`, поля
`RGB(45,45,45)`, светлый текст, тёмные owner-draw кнопки).

## Сборка на Windows XP (VS2008)

> **Не открывайте проект прямо с CD/DVD или ISO-образа (диск D:)!**
> Носитель только для чтения, и VS2008 не сможет загрузить `.vcproj`:
> «Project file … could not be loaded. The project is either missing
> from disk or access was denied.» Сначала скопируйте папку проекта
> на жёсткий диск, например в `C:\ATAAnalyzerLab`. Если файлы копировались
> с компакт-диска, снимите у папки атрибут «Только чтение»
> (Свойства → убрать галочку → Применить → к вложенным папкам и файлам).
> Надёжнее всего передавать проект в виртуальную машину одним ZIP-архивом
> и распаковывать его уже на `C:` — так ISO9660 не обрежет длинные имена.

1. Открыть `ATAAnalyzer.sln` (с диска `C:`) в Visual Studio 2008.
2. Выбрать конфигурацию **Release | Win32**.
3. Сборка → Собрать решение (F7). Готовый `ATAAnalyzer.exe` появится в
   папке `Release` рядом с `.sln`, post-build шаг сам скопирует туда
   `HexIO.sys`.

Настройки под XP уже внесены в проект: только x86 (`TargetMachine=MachineX86`),
`/SUBSYSTEM:WINDOWS,5.01`, `WINVER/_WIN32_WINNT = 0x0501`, статическая CRT
(`Release` — `/MT`, как и `hexiosupp.lib`), поэтому **VS2008 Redistributable
на чистой XP не нужен**. Для Debug линкер может дать предупреждение LNK4098
(готовая `hexiosupp.lib` собрана с `/MT`) — для запуска на XP используйте
Release.

## Запуск

- Только Windows XP **x86**, от имени **администратора** (драйвер HexIO
  ставится как служба).
- `HexIO.sys` должен лежать **рядом с `ATAAnalyzer.exe`** (библиотека
  HexIO ищет его по текущему каталогу, программа при старте выставляет
  текущим каталогом папку с exe). Если файла нет — программа прямо напишет
  ожидаемый путь. Оставшуюся от прошлых запусков службу `hexio` с чужим
  путём программа переустанавливает сама; вручную это делается командами
  `sc stop hexio` и `sc delete hexio`.
- Нужен IDE-контроллер: на реальной машине — legacy IDE режим, в
  VirtualBox — контроллер хранилища типа PIIX3/PIIX4 (диск на Primary
  Master, CD-ROM при желании на Secondary).
